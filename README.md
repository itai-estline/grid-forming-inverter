# Grid-Forming Inverter

A scrollytelling site about my independent grid-forming inverter project (simulation and packaging design), plus a standalone 3D viewer of the packaged unit.

- Site: https://itai-estline.github.io/grid-forming-inverter/
- 3D viewer: https://itai-estline.github.io/grid-forming-inverter/viewer.html

Static HTML, CSS and JavaScript with three.js. No build step.
